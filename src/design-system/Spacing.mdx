## Radius

Computed live from the single `--radius` token in
[`tokens.css`](./tokens.css) using the same formula as `index.css`'s
`@theme inline` block — change `--radius` there and every swatch below (and
every `rounded-*` utility in the app) moves together.

export const RadiusSwatch = ({ name, formula }) => (
  <div style={{ display: "flex", flexDirection: "column", alignItems: "center", gap: 8 }}>
    <div
      style={{
        width: 72,
        height: 72,
        background: "var(--sage-soft)",
        borderRadius: formula,
      }}
    />
    <span style={{ fontFamily: "var(--font-mono)", fontSize: 11 }}>{name}</span>
  </div>
);

<div style={{ display: "flex", gap: 24, marginBottom: 32 }}>
  <RadiusSwatch name="sm" formula="calc(var(--radius) - 4px)" />
  <RadiusSwatch name="md" formula="calc(var(--radius) - 2px)" />
  <RadiusSwatch name="lg" formula="var(--radius)" />
  <RadiusSwatch name="xl" formula="calc(var(--radius) + 4px)" />
  <RadiusSwatch name="full" formula="9999px" />
</div>

Two exceptions exist in the shipped app, both hardcoded rather than sourced
from the token: the hero and team-monitor cards use Tailwind's un-overridden
`rounded-2xl` (16px), and the sticky note uses a literal `10px` that happens
to equal `lg` by coincidence.

## Spacing scale, as used

Tailwind's default scale — not exposed as a custom property in this app, so
shown here as documented convention rather than a live-bound value.

## Elevation

<Table headers={["Tier", "Used for"]} rows={elevation} />

The Retro Prep sticky note has its own bespoke, three-state elevation
(rest / dragging / starred) — see `StickyNote.tsx` — deliberately separate
from this flat scale, since it's selling a physical paper-on-a-board
metaphor rather than a UI surface.
