# Colors

Every swatch below paints from the actual CSS custom properties in
[`tokens.css`](./tokens.css) — nothing here is a hardcoded hex/oklch copy.
Toggle below and every swatch repaints, because the app's real `dark` class
is what's actually toggling.

## Semantic pair — Sage & Clay

The one rule every score, status, and trend in Vitals follows: **Sage** reads
positive, **Clay** reads "worth a look" — a warm terracotta standing in for
red, deliberately softer so nothing reads as an alarm.
